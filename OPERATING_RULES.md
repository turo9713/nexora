# Nexora Operating Rules

## Main rules
- All tasks go through Orchestrator.
- Each agent works only within its own responsibility area.
- Dangerous actions require owner confirmation.
- Agents cannot raise their own privileges.
- Secrets are never stored in memory.
- QA checks the final output before delivery.

## Safety constraints
- Workspace-only execution.
- No root access.
- No sandbox bypass.
- No external messaging without confirmation.
- No financial or trading actions.
- No destructive actions.
- No unverified plugins or unknown code.
