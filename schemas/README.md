# Nexora Schemas

Canonical data contracts for Nexora runtime.

## Source of truth
- Task → `task.schema.json`
- Agent communication → `agent_message.schema.json`
- Agent output → `agent_result.schema.json`
- Human approval → `approval.schema.json`
- Files → `artifact.schema.json`

## Notes
- `result.schema.json` is deprecated and kept only as an alias/deprecation marker.
- Use the canonical schemas above for all runtime data contracts.
