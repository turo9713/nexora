- [x] README and public documentation prepared.
- [x] MIT license and security policy added.
- [x] Full test suite passes on the release commit.
- [x] Git worktree and history secret scans pass.
- [x] Release Compose validates and hardening tests pass.
- [x] Clean isolated installation reaches healthy state.
- [x] Offline demo completes without network or publication.
- [x] Generic rollback is tested in an isolated clone.
- [x] Tag `v2.0.0` points to the verified release commit.

Unchecked items are completed only after factual verification during the
release procedure. The final report must not mark the release ready otherwise.
