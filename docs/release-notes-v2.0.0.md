# Nexora v2.0.0 — First Public Release

Nexora is a self-hosted AI agent platform.

## Features

- Multi-agent runtime and task orchestration
- Declarative Skills system and Policy Engine
- Authenticated Dashboard and scoped API layer
- Safe integrations, approvals, audit, events, and metrics
- Hardened Docker deployment and offline demo

## Architecture

OpenClaw Runtime + Nexora Control Plane + Skills Ecosystem.

## Security

- Deny-by-default policies
- One-time approvals for risky actions
- Sanitized audit logging
- Isolated non-root execution and protected secret handling
