# Publishing

1. Register a publisher from the protected Dashboard.
2. An administrator reviews and approves the publisher identity.
3. Submit a declarative manifest through the Dashboard or scoped API.
4. Nexora validates schema, permissions, compatibility, and integrity.
5. Approved metadata appears in the catalog.

Publisher verification is one-time and audited. A pending or suspended
publisher cannot publish. The author string is display metadata; ownership is
resolved from the authenticated internal namespace and publisher record.

Do not submit source code, binaries, install scripts, URLs to dependency
installers, secrets, credentials, environment values, or production config.
