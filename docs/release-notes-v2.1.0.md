# Nexora v2.1.0

Community, Templates & First Users release.

- Five reviewed declarative workflow templates.
- Owner-isolated, reversible template installations through Policy Engine and existing approvals.
- Authenticated Dashboard and scoped Public API template endpoints.
- Safe data-only Playground with no external actions.
- Community Skills review structure, onboarding, public demos, and anonymous community metrics.
- Reversible SQLite migration 005 and expanded Linux CI coverage.

The OpenClaw Gateway remains private. Templates and Playground cannot grant shell, root, Docker, secrets, production access, or automatic publication.
